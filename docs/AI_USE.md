The assignment (PDF p.1–2) allows AI assistants but requires naming the tools, what they were
used for, and how their output was tested or corrected. This file records the division of work
for this project honestly, item by item.

**Roles in one sentence:** the student (Muhammad Ali, i230008) defined the requirements, the
constraints and the working method, provided the interface design, made the practical project
decisions and reviewed the results; **Claude Code (Anthropic, Claude Opus 5.5)** implemented the
code, ran the experiments on the student's machine, proposed the detailed technical choices
(listed in §3, all accepted by the student) and drafted the documentation.

Legend for the "Decided by" columns:
- **Student** – stated by the student (in the written project brief or during the project).
- **Claude → accepted by student** – proposed by Claude Code with a justification in

## 3. Technical choices proposed by Claude Code and accepted by the student
Each choice is justified with sources in `docs/research_notes.md` (section given).

| Choice | Alternatives considered | § |
|---|---|---|
| Python 3.11 venv with CUDA PyTorch 2.14 (system Python 3.14 had CPU-only torch) | system Python | – |
| Oxford-IIIT Pet from the timm mirror, verified against the official split files + MD5 of official images | official server only (~150 KB/s) | 1.6 |
| Occlusion coverage = **union** of rectangles; whole-pixel salt-and-pepper; reflect-padded blur | sum of areas; per-channel noise; zero padding | 1.1–1.3 |
| Validation manifest with all four conditions per image | one random condition per image | 1.4 |
| Balanced batch sampler (exactly B/4 per condition) | random sampling | 1.5 |
| Selection objective J = 0.5·L1 + 0.5·(1−SSIM), independent of α | training loss as objective | 2.5 |
| Bottleneck *shape* search (8×8 or 16×16 grid, 12–48× compression) after the first real trial | latent channels only | 2.2 |
| Bilinear upsampling + conv decoder | transposed convolutions | 2.1 |
| Classifier with average + max pooling, AdamW | average pooling only, Adam | 3.1 |
| CE on untempered gate logits; expert BatchNorm statistics frozen during joint training | CE on tempered logits; trainable BN stats | 4.2–4.3 |
| Marginal-entropy loss as the balance alternative (noting the PDF loss equals Shazeer's CV² up to a factor 4) | Switch-Transformer loss | 4.4 |
| Style conditioning by embedding concatenation at G input + bottleneck and D input | FiLM / conditional norm, projection discriminator | 5.2 |
| InstanceNorm in the GAN; 1-channel sketch output (FS2K sketches are grayscale) | BatchNorm; RGB output | 5.1, 5.3 |
| No FID (biased for ~1k images, unsuited to line drawings) | FID / KID | 5.6 |
| MLflow with local SQLite (no account needed) | Weights & Biases | 6 |
| GitHub Releases for model files | Git LFS, Hugging Face | 6 |
| torch.export-based ONNX exporter, atol 1e-4 validation; MoE exported as one graph, hard routing as four graphs + backend argmax | legacy exporter | 4.6, 6 |
| Backend without PyTorch, reusing the NumPy corruption code; images as base64 PNG in JSON | separate JS corruption code; binary responses | 6 |

## 5. Problems found and corrected
- Float-equality bug in a test → `pytest.approx`.
- ONNX exporter crashed on the Windows console encoding → UTF-8 output.
- Official dataset server ignored HTTP range requests → verified mirror.
- First Task 1 search space too narrow (low SSIM in the first real trial) → bottleneck-shape search, study restarted.
- Smoke-test tables written into the report folder → only FINAL results may enter `report/`.
- pandas 3 incompatibility crashed the Task 3 evaluation → fixed and re-run.
- Background training killed by a session time limit / closed window → relaunched as detached processes; Optuna studies resumed.
- Docker build failed with a false pip dependency conflict → all backend dependencies pinned.
- Windows line endings in the release checksum file broke `sha256sum -c` → LF-only file.
