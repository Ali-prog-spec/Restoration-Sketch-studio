# Data

Datasets are **not** committed (see `.gitignore`). Everything under `data/raw` and
`data/processed` is regenerated by scripts. `data/manifests/` IS committed: it contains the
fixed splits and the deterministic corruption manifests.

## Oxford-IIIT Pet (Tasks 1–3) — Parkhi et al., CVPR 2012, CC BY-SA 4.0

Option A (official server, slow — ~150 KB/s per connection):
```bash
python scripts/prepare_oxford.py --download
```
Option B (verified mirror, fast):
```bash
mkdir -p data/raw/oxford_pets/hf
curl -L -o data/raw/oxford_pets/annotations.tar.gz https://thor.robots.ox.ac.uk/datasets/pets/annotations.tar.gz
tar -xzf data/raw/oxford_pets/annotations.tar.gz -C data/raw/oxford_pets
curl -L -o data/raw/oxford_pets/hf/train.parquet https://huggingface.co/datasets/timm/oxford-iiit-pet/resolve/main/data/train-00000-of-00001.parquet
curl -L -o data/raw/oxford_pets/hf/test.parquet  https://huggingface.co/datasets/timm/oxford-iiit-pet/resolve/main/data/test-00000-of-00001.parquet
python scripts/fetch_oxford_mirror.py        # writes images/ and verifies against the official files
python scripts/prepare_oxford.py             # RGB, 128x128 cache, 80/20 split (seed 42)
```
Then, **once**:
```bash
python scripts/generate_manifests.py         # deterministic val/test corruption manifests
```

| File | Content |
|---|---|
| `manifests/oxford_split.json` | 2,944 train / 736 val (from official trainval, seed 42) / 3,669 official test ids |
| `manifests/oxford_val_manifest.json` | 2,944 records: 4 conditions per val image, training-range severities |
| `manifests/oxford_test_manifest.json` | 36,690 records: clean + 3 corruptions × 3 fixed levels per test image |
| `manifests/oxford_source_verification.json` | mirror-vs-official check (split ids + MD5 of overlapping images) |
| `processed/oxford_{trainval,test}_128.npy` | clean RGB 128×128 uint8 cache (speed-up only; no corrupted images) |

## FS2K (Task 4) — Fan et al., Machine Intelligence Research 2022

Download `FS2K.zip` from the official repository (https://github.com/DengPingFan/FS2K, Google Drive
link in its README) into `data/raw/`, then:
```bash
python scripts/prepare_fs2k.py --download    # or unzip manually to data/raw/FS2K and omit --download
```
`manifests/fs2k_split.json`: official train (1,058) split into 899 train / 159 val, stratified by
style, seed 42; official test (1,046) kept separate and only used by `scripts/evaluate_task4.py`.
