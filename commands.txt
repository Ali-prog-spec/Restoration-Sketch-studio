10. TROUBLESHOOTING
---------------------------------------------------------------------
"npm error Missing script: dev"  -> you are not in the frontend folder: cd frontend
{"detail":"Not Found"}           -> you opened the backend (port 8000); open port 5173
Sidebar says "Backend offline"   -> backend terminal (section 1, terminal 1) is not running
Task 4 says model missing        -> training not finished yet / run scripts/export_onnx.py
Port already in use              -> an old server is still running; close its window or
                                    PowerShell: Get-Process python,node | Stop-Process
                                    (careful: this also stops a running training!)
